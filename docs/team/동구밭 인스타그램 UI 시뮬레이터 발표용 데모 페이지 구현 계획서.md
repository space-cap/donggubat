# 🌿 동구밭 인스타그램 UI 시뮬레이터 발표용 데모 페이지 구현 계획서

## 개요
발표 시 카드뉴스의 실감 나는 연출과 브랜드 무드를 극대화하기 위해, 실제 인스타그램 계정에 피드가 올라간 것과 같은 효과를 주는 **인터랙티브 인스타그램 스마트폰(iPhone) UI 시뮬레이터** 페이지를 제작합니다. 

단순히 이미지만 슬라이딩되는 것을 넘어 좋아요 애니메이션, 실제 피드 캡션 및 해시태그 스크롤, 프리미엄 글래스모피즘(Glassmorphism) 발표 배경을 포함하여 최고의 발표 효과를 연출합니다.

---

## 🎨 주요 디자인 및 기능 명세

### 1. 📱 iPhone 디바이스 프레임 디자인
- 미니멀하고 세련된 모던 베젤의 스마트폰(iPhone) 기기 프레임을 화면 중앙에 3D 섀도우와 함께 배치합니다.
- 상태 표시줄(상단 시간, 와이파이, 배터리 아이콘) 및 하단 홈 바 영역을 구성하여 진짜 스마트폰처럼 보이게 합니다.

### 2. 📸 인스타그램 피드 인터랙션 (카드뉴스 스와이프)
- 동구밭 공식 로고와 프로필 이름(`@donggubat_story`), 위치(`동구밭`) 영역을 상단에 렌더링합니다.
- 1:1 정방형 카드뉴스 이미지 6장([slide_1.png](file:///c:/workdir/space-cap/donggubat/docs/team/images/output/slide_1.png) ~ [slide_6.png](file:///c:/workdir/space-cap/donggubat/docs/team/images/output/slide_6.png))을 배치합니다.
- 마우스 드래그 및 터치 스와이프, 하단 인디케이터 도트(1/6 ~ 6/6)가 동적으로 변경되는 터치 프렌들리 **카러셀(Carousel)**을 바닐라 JS로 구현합니다.

### 3. ❤️ 좋아요 마이크로 애니메이션 및 소셜 기능
- 인스타그램의 핵심 인터랙션인 '좋아요(하트)' 버튼 클릭 시, 하트 아이콘이 붉게 물들며 팡 터지는 탄성 애니메이션을 적용합니다.
- 이미지 영역을 더블 클릭해도 화면 중앙에 커다란 하트가 팝업되며 좋아요 상태로 전환되는 기능을 추가합니다.
- 저장(북마크), 댓글, 공유 아이콘을 탑재하여 현실감을 더합니다.

### 4. 📝 캡션 및 해시태그 스크롤 영역
- 하단 피드 소개 텍스트에 실제 인스타그램처럼 더보기(`...더 보기`) 버튼과 클릭 시 펼쳐지는 아코디언 인터랙션을 구현합니다.
- 동구밭 Q3 구독 캠페인 내용과 친환경 해시태그를 포함하여 스크롤 가능하게 배치합니다.

### 5. 🌿 프리미엄 프레젠테이션 배경 (Glassmorphism)
- 발표 스크린 전체 화면(Background)에 동구밭 브랜드의 키 컬러인 '딥 올리브 그린'과 '오가닉 베이지'가 조화롭게 어우러지는 은은한 그라데이션 및 블러 섀도우를 연출합니다.
- 스마트폰 모형 뒤에 아티스틱한 유기농 식물 잎 실루엣 이미지를 배치하여 프리미엄 감성을 표현합니다.
