
# 동구밭(Donggubat) 숏폼 광고 AI 제작 시나리오

> **제작 방식:** 4개 클립 각각 ① AI 이미지 생성 → ② 이미지-to-비디오 변환 → ③ 4개 클립 편집 연결 → 1편 완성

## 🔗 편집·연결 가이드

| 항목 | 가이드 |

|---|---|

| 전환(Transition) | 1→2: 빛 번짐(light leak) / 2→3: 물방울 와이프 / 3→4: 거품→햇살 디졸브. 자연 소재로 이어 붙이면 매끄러움 |

| 자막 스타일 | 하단 1/3 배치, 산세리프 + 부드러운 페이드 인/아웃, 동구밭 톤(세이지 그린·크림) 컬러 |

| BGM | 어쿠스틱 기타 + 잔잔한 퍼커션, 후반부로 갈수록 밝아지는 곡. 클립3에서 비트 강조(물 splash 싱크) |

| 페이싱 | 1·2클립은 여유롭게, 3클립에서 텐션 업, 4클립에서 안정적 마무리 |

| 컬러 그레이딩 | 4클립 모두 동일 LUT 적용(따뜻한 어스톤)으로 통일감 확보 |

| 일관성 팁 | 4개 이미지 생성 시 동일 seed·동일 앵커 프롬프트 유지, 동일 카메라 룩(35mm) 명시 |

## ✅ 제작 체크리스트

1. 앵커 프롬프트 확정 → 4개 이미지 일괄 생성(동일 seed 시도)

2. 클립3·4는 **실제 제품/패키지 이미지 첨부** 후 생성

3. 각 이미지를 i2v 프롬프트로 영상화(슬로모션·다이내믹 모션 강조)

4. 컷 편집 → 전환 → 자막 → BGM → 컬러 그레이딩 → 엔드 카드

5. 9:16 / 1080×1920 / 30fps 이상으로 출력
