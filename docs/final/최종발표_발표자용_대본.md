### [Slide 5] 동구밭의 공식: Product First, Value Later
* **머리가 하얘졌을 때 치트키:** 가치 호소 거부 ➔ 좋아서 구매 ➔ 재구매 ➔ 가치 발견 ➔ 락인
* **스피치 가이드:** 
  * "품질은 진입을 돕고, 가치는 이탈을 막는다"를 강하고 신뢰감 있게 선포합니다.
  * 3단계 흐름(진입 ➔ 루틴 ➔ 락인)에 맞춰 천천히 설명합니다.
* **스피치 대본:**
  > "이 때문에 동구밭은 마케팅의 공식을 완전히 비틀었습니다. / 착하니까 사달라고 호소하지 않습니다.
  > 
  > 전략은 간단합니다. / **'Product First, Value Later'** (쉬고)
  > 먼저 압도적인 제품력으로 일상의 문제를 해결해 줍니다. / 마음에 들어서 계속 씁니다. / 매일 쓰다 보니 패키지에 새겨진 점자를 만지게 되고, / 100% 생분해 포장재와 발달장애 가꿈지기들의 땀방울을 나중에야 발견하게 됩니다.
  > 
  > 즉, **'품질은 진입 장벽을 낮추고, 가치는 이탈 장벽을 높여주는'** / 동구밭만의 강력한 고객 락인(Lock-in) 공식이 완성되는 순간입니다."
